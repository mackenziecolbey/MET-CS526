#Introduction: This assignment covers palindrome checking, recursive substring generation, line intersections, and stack implementations. Problem 1 checks if input strings are palindromes, and spaces are ignored. The program also counts the number of palindromes. Problem 2 finds all unique, nonempty substrings of an input string. The substrings are printed in alphabetical order, then by the total number of unique substrings. Recursion is used to process different starting positions in the string. Problem 3 implements three types of stacks: array-based, singly linked, and doubly linked. Each implementation supports push, pop, peek, and its_empty operations. Then, each stack is reversed using recursion. Problem 4 determines whether any two streams intersect. Each stream is an infinite line defined by a Ghostbuster's coordinates and the coordinates of the corresponding ghost. The program checks every pair of streams and determines whether they intersect, including when 2 streams are on the same line. 
#Algorithm: Problem 1 (palindromes): The program reads input one line at a time until there's no more input. It removes spaces from each line and compares the resulting string with its reverse. If the two strings match, then it prints "True" and increases the palindrome count. Otherwise, it prints "False". After all the lines are processes, it prints the total number of palindromes. Problem 2 (unique substrings): The program reads a string and uses a recursive function to process each starting position. For each position, it generates the substrings that begin there and adds them to the set. The set prevents duplicate substrings from being counted more than once. The program then sorts the set alphabetically, prints each substring, and prints the total number of unique substrings. Problem 3 (stack implementations): Three stack implementations are created, array-based, singly linked, and doubly linked. Each stack supports push, pop, peak, and is_empty operations. To reverse a stack, the program recursively removes elements until the stack is empty. It insets each removed element at the bottom of the stack as the recursive calls return. This reverses the order of the elements without using loops in the reversal. The program insets values 1 through 10 into each stack, then prints the original order, reverses the stack, then prints the new order. Problem 4 (Stream Intersection): Each stream is represented by 2 points, the Ghostbuster's position and the ghost's position. The program uses direction vectors and cross product to compare pairs of infinite lines. If the direction vectors aren't parallel, the lines intersect. If they are parallel, the program checks whether the lines lie on the same line. Parallel lines at different positions won't intersect. The program checks every pair of streams. If any pairs intersect, it prints "All Ghosts: were not eliminated". If no pair intersects, it prints "All Ghosts: were eliminated".
#Interesting: An interesting part of the assignment was reversing the stacks recursively without using a second stack. Problem 4 was also interesting because the streams represent infinite lines, so even lines that don't cross between the two given points may still intersect.
